# BenDavid OS vault

Open **index.md** first. It is the master index, maintained by BenDavid OS.

In Obsidian: *Open folder as vault* → choose this `vault` folder. It is separate from any vault you already have, and BenDavid OS never edits other vaults.

| Folder | What it holds | Who writes it |
| --- | --- | --- |
| `raw/` | Original inputs you intentionally provide (emails, notes, documents) | You (or **Knowledge → Add to raw/**). Never edited by the app. |
| `wiki/` | Organized, source-linked knowledge, including derived client views | BenDavid OS |
| `output/` | Reports and drafts from workflow runs (never sent) | BenDavid OS |
| `daily-notes/` | Dated plans and reviews | Both: the app owns only the generated Plan section |
| `projects/` | Context for each project (Delta Capital first) | You |
| `system/` | Operating rules, writing preferences, routing, automation, plugin interface | You (plus generated registry/migration notes) |

Generated content and anything containing client details (`raw/`, `wiki/`, `output/`, `daily-notes/`, indexes) is excluded from git.
