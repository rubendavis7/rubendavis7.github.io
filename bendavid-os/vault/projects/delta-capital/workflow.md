# Delta Capital workflow

## Deal stages
**Statements → Offer → Accepted → Contract → Bank Verification → Funding Call → Funded**

| Stage | Done when | Typical next action |
| --- | --- | --- |
| Statements | Bank statements (by month) and application received | Submit file to funders |
| Offer | Funder offer confirmed and shared | Get a decision from the owner |
| Accepted | Owner accepts the offer | Send contract for e-signature |
| Contract | Contract signed | Bank verification |
| Bank Verification | Funder verifies the account | Schedule funding call |
| Funding Call | Call completed | Confirm funds land |
| Funded | Funds received | Check in, ask for referrals, track renewal |

## Standard document requests
- Business bank statements, tracked **by month** (for example July, August, September 2026)
- Month-to-date statement
- Signed application
- Driver's license
- Voided business check

## Daily routine in BenDavid OS
1. **Plan My Day**: writes today's plan into `daily-notes/`.
2. Clear P1 items first (overdue follow-ups, deals near funding).
3. **Find Missing Statements**, then **Prepare Follow-Up** for each client waiting on documents.
4. Review each draft, copy it into your email, and send it yourself.
5. Update stage, last contact, and next follow-up after every touch.
6. **Review Pipeline** on Fridays.
