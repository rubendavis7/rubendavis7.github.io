# Workflow

## Deal stages
**Statements → Offer → Accepted → Contract → Bank Verification → Funding Call → Funded**

| Stage | Done when | Typical next action |
| --- | --- | --- |
| Statements | Bank statements and application received | Submit file to funders |
| Offer | Funder offer confirmed and shared | Get a decision from the owner |
| Accepted | Owner accepts the offer | Send contract for e-signature |
| Contract | Contract signed | Bank verification |
| Bank Verification | Funder verifies the account | Schedule funding call |
| Funding Call | Call completed | Confirm funds land |
| Funded | Funds received | Check in, ask for referrals, track renewal |

## Standard document requests
- Business bank statements (last 4 months)
- Month-to-date statement
- Signed application
- Driver's license
- Voided business check

## Daily routine
1. Open BenDavid OS → **Plan My Day**.
2. Clear P1 items first (overdue follow-ups, deals near funding).
3. **Missing Statements** → send document requests.
4. **Prepare Follow-Up** for each client due today; review and send from email yourself.
5. Update stage, last contact, and next follow-up date after every touch.
6. **Save daily report to vault** at end of day.

## Instructions for future AI assistants
- Read [[Writing Preferences]] before drafting anything.
- Client facts come only from the BenDavid OS data store, never from memory or Clients/ notes.
- Drafts only. Never send email or texts.
